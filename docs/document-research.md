# Evidence for the ZeroUpfront design

Reviewed 21 November 2026. The design decision is to use Astra for transcription when the text layer is untrustworthy, retrieve the applicable policy evidence, and show both the source page and the case evidence to staff. The three operations have different failure modes and need separate measurements.

## Preparation decision

Use the hybrid retriever and page-level Astra fallback for the synthetic demonstration. The operating question for a pilot is whether the system helps staff catch a material missing or incorrect item **before** they send a request. Track deposit collection and insurer turnaround separately: both depend on decisions outside this system. A reviewer should be able to reconstruct each proposed amount from the selected edition, original case revision, dated limits, currency and independently checked line calculations. [Bumrungrad finance guidance](https://www.bumrungrad.com/th/medical-travel/patient-finance-insurance-information) · [Bangkok Hospital Pattaya insurance guidance](https://www.bangkokhospital.com/en/visit/insurance-bph)

## Independent reproduction

The audit rechecked both file hashes and page counts, the US overseas section, native text corruption on the Thai benefit table, and the six recorded OCR anchors. The six keys were the bilingual benefit heading, the English ICU room label, the 2× multiplier, the 15-day limit and subsections 2.4 and 4.2. Compare against physical page 20 of the PDF, using Unicode NFC, whitespace removal and case folding. An anchor can survive while the associated value moves to the wrong column. Reproducing the original paid inference timing requires a fresh live run and the same model, whereas a fresh lexical evaluation only requires the locked dependencies and synthetic PDFs.

```sh
shasum -a 256 .local/references/us-opm-2026.pdf .local/references/th-allianz-superior.pdf
uv run --locked python app/eval_documents.py
uv run --locked python app/eval_documents.py --samples ZeroUpfront-training-samples
```

The first Python command rechecked **11/11 required page instances across six authored questions** with the local retriever. The second validates the supplied JSONL structure and the train/evaluation ID split when that folder is available. For an independent challenge, have a hospital coordinator write questions before seeing model hits and have a separate reviewer label controlling clauses, case evidence and exceptions. Include a wrong-edition decoy, a rider that narrows a benefit, a missing enrollment schedule, an unreadable table cell and a request with no applicable policy evidence. Count an unsupported ready draft as a failure even if every quoted phrase appears somewhere in the packet.

## OCR choice and cost

OpenAI's public model catalog and API reference document OCR through a vision-capable model on Responses. I found no standalone general-purpose OCR endpoint. PDF input includes extracted text and rendered page images. The PDF detail parameter supports high; the vision guide separately describes original detail for supported image inputs. The implementation submits a single physical PDF page with high detail and preserves the original digest and page number. Illegible or partial transcripts stop the evaluation. A model can still confidently misread a zero, a decimal, a Thai vowel or a benefit column. [OpenAI model catalog](https://developers.openai.com/api/docs/models) · [PDF inputs](https://developers.openai.com/api/docs/guides/file-inputs) · [Vision](https://developers.openai.com/api/docs/guides/images-vision)

Astra can handle multilingual visual interpretation and output a structured transcription using the hackathon API key. At the published standard short-context rates of $8 per million input tokens and $40 per million output tokens, an illustrative 10,000 input tokens and 1,500 output tokens costs $0.14. Measure billed usage including reasoning for your own pages. Dense multipage PDFs can cost much more. Native digital extraction avoids inference when the page is reliable. [OpenAI pricing](https://developers.openai.com/api/docs/pricing) · [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)

For a later procurement comparison, Google Enterprise Document OCR offers document-quality signals and token-level layout. Mistral Document AI offers block geometry and confidence scores. These capabilities matter if the reviewer must highlight a precise cell or route low-confidence tokens at scale. Astra is the hackathon choice given the available account and the need to reason over the evidence. Its superiority on Thai insurance tables is an open empirical question. ThaiOCRBench includes distinct full-page OCR, table and extraction tasks and provides a useful external evaluation design. [Google Document AI](https://docs.cloud.google.com/document-ai/docs/enterprise-document-ocr) · [Mistral OCR](https://docs.mistral.ai/studio/document-processing/basic_ocr) · [ThaiOCRBench paper](https://aclanthology.org/2025.ijcnlp-long.89/)

## Why retrieval and how to evaluate it

A larger model can read a long single PDF, but a reviewer must identify the controlling policy edition, exceptions and supporting pages. The current live demo scopes to one policy bundle, uses BM25 for terms and codes plus text-embedding-3-small for paraphrases, fuses the rankings, and supplies selected evidence to Astra. The short synthetic packet accompanies the policy evidence. After generation the program checks each quoted string on its referenced page. Quote presence and policy interpretation require distinct checks. [OpenAI embeddings](https://developers.openai.com/api/docs/guides/embeddings) · [Contextual retrieval experiments](https://www.anthropic.com/research/contextual-retrieval)

OpenAI File Search can host chunking, embeddings and search. The tradeoff is that the application still has to map retrieved material to PDF pages, enforce edition/tenant scope and manage stored files. An application-controlled policy index is easier to inspect for a disputed source reference. The local vector cache is scoped to policy text; moving to PostgreSQL and pgvector later preserves the evidence contract. Private case packets should have their own retention and authorization rules in the shared app. [Hosted retrieval](https://developers.openai.com/api/docs/guides/retrieval) · [File Search citations](https://developers.openai.com/api/docs/guides/tools-file-search) · [Provider data controls](https://developers.openai.com/api/docs/guides/your-data)

**Measured results, 21 November.** Both local lexical search and live hybrid retrieval found all 11 labeled pages across the six synthetic questions at k=4. This test alone gives no reason to pay for embeddings. On the real US brochure, the same overseas question against 369 passages returned physical pages **24, 24, 85, 21** with lexical search. It missed the controlling overseas section on page 131. Adding embeddings and reciprocal rank fusion returned **24, 24, 131, 85** in 5.45 seconds for the initial embedding/search run. The query explicitly names the overseas exception categories. It tests a known failure mode and provides a weak estimate of performance on unseen staff questions. Both methods used two slots on page 24. Evaluate page diversity and references to endorsements on a larger blind set.

**Live end-to-end Thai case.** With the synthetic Thai statement's fourth page rasterized, the live pipeline transcribed the page, retrieved policy pages 4, 7, 8 and 6, and produced a staff draft in **33.935 seconds** on one run. The answer reconciled **THB 144,000** net charges, **THB 1,000** room excess and **THB 1,200** for the companion bed, yielding **THB 141,800** requested. Policy and case quote checks passed, including a reference to the scanned page. This run timed the CLI through verified answer generation. It does not include a browser upload, human review or GOP PDF export.

**One-page head-to-head on real Thai wording.** On physical page 20 of the Allianz PDF, Astra produced a transcript in 13.16 seconds. Six visual spot checks covered the bilingual benefit heading, English ICU room label, multiplier, maximum duration and two subsection numbers. With whitespace removed and case folded, Astra preserved 6/6, native extraction 6/6, and the previous Tesseract configuration with Thai and English language data 5/6. Tesseract missed the exact bilingual heading. Six strings do not measure full-page Thai error rate, correct association of merged cells or comparative reliability across hospitals. This supports keeping the digital text path and using Astra for scans or damaged text.

```sh
uv run --locked python app/public_policy_search.py .local/references/us-opm-2026.pdf "Overseas inpatient hospital precertification prior approval exceptions residential treatment centers skilled nursing facilities overseas assistance"
uv run --locked --env-file .env python app/document_text.py .local/references/th-allianz-superior.pdf --page 20 --force-vision --live
```

**Supplied held-out set.** We checked that the 14 training IDs and 7 evaluation IDs are disjoint. A live baseline using only the provided prompts and generic JSON output matched 0/67 expected top-level fields exactly. The tasks do not specify the expected field naming convention. We then defined typed billing, medical-record and GOP output contracts from the training split and repeated the evaluation. The structured run matched 40/67 fields: 20/33 billing, 10/16 records and 10/18 GOP. Each field is compared strictly, including wording in free-text fields and order in lists. This is an interface regression score, not a clinical accuracy estimate. One held-out GOP case still missed the expected draft amount, and policy evidence and source lists also diverged. Before any pilot, independently compute amounts and score numeric accuracy, exact evidence references and semantic completeness separately. No fine-tuning was performed.

**Next benchmark.** Label page transcription independently from coverage. Compare native text, Astra and a specialist OCR model on identical pages. Score exact currency/amounts and clause IDs, Thai character error rate, correct table cells and unreadable-page handling. For retrieval, report recall of all controlling pages including exceptions, wrong-edition retrieval and unsupported answers. For generation, score the case and policy citation independently, packet arithmetic, missing inputs and abstention. Report p50/p95 latency and actual billed cost per page and case. The earlier local OCR benchmark is historical. The one-case timing and the one-page spot check above are initial measurements. No invoice-based per-case cost or representative p95 is available.
