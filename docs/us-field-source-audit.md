# Source audit of the field-specific verifier

Every one of the **70 substantive field assignments** in this run had the correct typed value and evidence attached to that same field that located its operative clause or table row. English and Thai each scored 35/35 fields and 16/16 fully supported answerable scenarios. Each language also had two member-specific questions for which the verifier correctly returned null with no citation. The counts represent the same 18 authored scenarios asked twice against one English-language policy. [Pinned OPM source](https://www.opm.gov/healthcare-insurance/healthcare/plan-information/plans/pdf/2026/brochures/71-005.pdf) · [Field annotations](../bench/us_field_source_audit.json)

## Review method

I grouped the returned anchors by scenario and field and compared all 63 distinct scenario/field/page/text combinations with the original PDF layout and numbered page text. I then checked the actual grouping of each output's own citations. There were 98 citation occurrences across 36 outputs. A field passed if its typed value matched the pre-existing label, each submitted anchor matched a supplied source page, and its own anchor set located an operative paragraph, bullet or table row establishing the field within the stated scenario. Headings and neighbouring labels were available to the reviewer who opened that anchor. A broad heading by itself received no independent evidentiary weight. The same project reviewer previously authored the source labels and reviewed the first-pass citations. This was a semantic spot-by-spot review by one reviewer, separate from automatic string matching and page scoring. [Earlier page-citation audit](us-citation-audit.md)

The enrollment test checked the actual row and column. The English code field cited the front cover, where Basic Self Plus One carries code 113. Both language outputs for the premium field included the physical rate-table header and the Basic Self Plus One row. The biweekly employee contribution is USD 319.25, which converts to 31,925 cents. Several digits and labels are split in the extracted text. The rendered table resolves the grouping. For the therapy scenario, page 81 contains a different set of limits for manipulative treatment just below the requested therapy limits. Each field-specific anchor identified the appropriate benefit and plan column or sub-bullet. [Cover](https://www.opm.gov/healthcare-insurance/healthcare/plan-information/plans/pdf/2026/brochures/71-005.pdf#page=1) · [Rates](https://www.opm.gov/healthcare-insurance/healthcare/plan-information/plans/pdf/2026/brochures/71-005.pdf#page=168) · [Therapy](https://www.opm.gov/healthcare-insurance/healthcare/plan-information/plans/pdf/2026/brochures/71-005.pdf#page=81)

The verifier's inputs included the union of pages identified by the first reads and the retrieval shortlist. This supplied the source pages for the difficult Thai hearing-aid and therapy questions. The result measures verification with those candidates available. It leaves open how the verifier behaves when all candidate sources omit an exception, different editions conflict, the applicable plan is uncertain, or a table cell cannot be read. A new source edition with independently labeled cases is needed before extrapolating this result.
