# Where the Decisions API fits

Reviewed 21 November 2026. Use the existing Responses, retrieval and calculation pipeline for the hackathon demo. Decisions is worth testing if routing incoming documents takes staff time. For example, given the same exhibit, it can choose among “itemized estimate”, “total-only estimate”, “other document” and “unclear”. The coordinator can then open the relevant page or request a better copy. The project brief asks for a source-grounded coverage pre-check and an insurer-format guarantee-of-payment request. Routing alone delivers neither.

| Task | Choice for ZeroUpfront | What the result gives staff |
| --- | --- | --- |
| Classify a known set of document types | Decisions can evaluate text, images and JSON. One request accepts up to 400 independent predicate, choice or rubric questions over shared evidence. The locked Python SDK 3.57.0 has `client.decisions.create`, and the generally available endpoint supports `gpt-6-luna`. | A choice, its probability distribution and a confidence field. An explicit “unclear” choice and thresholds evaluated on labeled examples allow staff review. [Decisions guide](https://developers.openai.com/api/docs/guides/decisions) |
| Read a scanned page and explain a policy exception | Responses can take a PDF's extracted text and page images, select a fixed enum through Structured Outputs, and return multiple fields including quotes, page references and an explanation. Retrieve the applicable policy edition first and verify each quote against its claimed page. | The original case passage, applicable policy clause and explanation needed to review the proposed finding. [PDF inputs](https://developers.openai.com/api/docs/guides/file-inputs) · [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs) |
| Reconcile the amount and release the draft | Apply explicit arithmetic and documented prerequisites to the verified line items and revision. Preserve an unknown amount if evidence is missing. | A reproducible calculation a coordinator can inspect. The insurer issues the eventual payment guarantee. [Financial checks and fixture scope](finance-gate.md) |

Both model endpoints can classify an image. Decisions adds per-option probabilities and efficient batching. OpenAI reports roughly 10× lower latency for these focused questions. That figure describes the provider's comparison. The team has yet to benchmark Decisions against Responses on Thai insurance scans. Before adding a second model call, compare both on the same held-out page images and labels. Count total-only estimates incorrectly classified as itemized, track the fraction sent to staff, and measure median and p95 end-to-end latency and cost per page. [Decisions guide](https://developers.openai.com/api/docs/guides/decisions#interpret-the-answers)

The Decisions guide also lists passage relevance as a use for a predicate. The team could score candidate passages as a separate ranking experiment. Its input would still need to include the governing rider. Our currently measured pipeline uses the managed search ranker and explicit embeddings. [Decisions guide](https://developers.openai.com/api/docs/guides/decisions) · [Measured rankers](embedding-eval.md)

## Hackathon credit and judging

OpenAI publishes a standard Decisions rate of **$0.10 per million uncached input tokens** and charges zero for output tokens on this endpoint. At that base rate, 10,000 input tokens cost $0.001 before applicable adjustments. OpenAI tailors support to each hackathon. The project brief supplies neither a judging requirement to use Decisions nor the $100 grant's eligible services. The organizer's rubric settles the first question. For the second, check the award terms, expiry and credit balance in the API organization that owns the project key. Keep Decisions optional unless the rubric calls for it or the comparison demonstrates a benefit. ## Codex Security for the tech lead

Enable **Codex Security** under **Plugins** in the desktop app. Open **Security**, select the ZeroUpfront checkout and run a standard scan to establish a baseline. Before merging a teammate's change to PDF uploads, case access or API key handling, ask Codex to “use `$codex-security:security-diff-scan` to review this pull request” and include the PR link. Review the cited code and suggested fix with the author.
